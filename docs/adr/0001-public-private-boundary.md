# ADR 0001: Publish control intent, retain delivery method

- Status: Accepted
- Date: 2026-08-13

## Decision

Publish control concepts, open profile schemas, fictional examples and selected reusable checks. Keep detailed scoring, customer mappings, threat models, commercial policy packs and delivery accelerators private.

## Consequences

Public controls require transparent sources and limitations. Private implementations may extend them but must not introduce customer information into public history.
