# Contributing

Contributions should be traceable, vendor-neutral and free from confidential information.

1. Open an issue describing the problem, evidence and intended contribution.
2. Cite exact versions of standards, guidance, legislation or research.
3. Mark proposals and assumptions clearly; do not present them as legal facts.
4. Use fictional examples and remove customer-identifiable details.
5. Add or update validation fixtures.
6. Submit a focused pull request using the repository template.

By contributing code or schemas, you agree that they are licensed under Apache-2.0. Documentation contributions are licensed under CC-BY-4.0.
