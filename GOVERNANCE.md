# Governance

The project is currently maintained by Fredrik.

Material changes to public semantics, required metadata or control intent should:

1. start with a documented issue;
2. cite sources and exact source versions;
3. record significant design decisions as ADRs;
4. include machine-readable validation where practical;
5. distinguish facts, interpretations, proposals and hypotheses;
6. receive maintainer approval before release.

The project is exploratory until explicit maturity and versioning criteria are adopted.
