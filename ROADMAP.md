# Roadmap

## 0.1 Foundation

- Define threat and assurance vocabulary.
- Establish source and control-reference register.
- Define profile versioning and compatibility rules.
- Add supply-chain and evidence metadata.

## 0.2 Control profile

- Map open security frameworks and relevant Swedish public-sector requirements.
- Separate control intent, implementation guidance and evidence.
- Add fictional conformance fixtures.
- Review with security, governance and archival experts.

## 0.3 Policy-as-code readiness

- Identify controls suitable for deterministic validation.
- Define inputs and evidence contracts.
- Publish selected open checks while retaining commercial delivery methods privately.
